1. Identitas dan Capaian Praktikum 
Modul ini melanjutkan project NavigationLab yang telah direfactor pada Modul Praktikum 06. Sumber data in-
memory diganti dengan layanan REST API eksternal agar mahasiswa memahami bagaimana aplikasi 
Android mengambil JSON melalui HTTP client, mengubahnya menjadi object Kotlin, dan meneruskan hasil 
tersebut melalui data layer hingga UI. 
Sub-CPMK terkait 
Mahasiswa mampu mengambil, mengolah, dan menampilkan data eksternal melalui REST API, JSON, HTTP client, 
dan/atau Firebase. Pada modul ini fokus diarahkan pada REST API + Retrofit; Firebase tidak digunakan. 
 
Capaian Praktikum 
Setelah praktikum, mahasiswa mampu mengonfigurasi akses jaringan Android, mendefinisikan endpoint 
Retrofit, memetakan JSON ke DTO, mengakses data melalui remote data source dan repository, serta 
menampilkan kondisi loading, success, dan error pada Jetpack Compose. 
Indikator Keberhasilan 
• Aplikasi memiliki permission INTERNET dan dapat mengakses endpoint HTTPS. 
• Retrofit mengubah endpoint REST menjadi fungsi Kotlin bertipe Call<T>. 
• JSON response dipetakan ke DTO, lalu diubah ke model yang digunakan aplikasi. 
• Composable UI tidak memanggil Retrofit secara langsung. 
• Repository tetap menjadi pintu akses data bagi ViewModel. 
• UI menampilkan kondisi loading, data berhasil, dan pesan error secara terpisah. 
• Navigation Home → Detail → Back tetap berfungsi setelah sumber data dipindahkan ke network. 
3. Konsep Singkat REST API, HTTP, dan JSON 
REST API menyediakan resource melalui URL (endpoint). Aplikasi mengirim HTTP request, server 
memproses request, lalu mengirim HTTP response. Body response sering menggunakan JSON. Pada 
Android, HTTP client seperti Retrofit membantu mendefinisikan endpoint sebagai interface Kotlin dan 
mengonversi JSON menjadi object.

Bagian Keterangan 
REST endpoint URL yang merepresentasikan resource, misalnya GET /users. 
HTTP method GET digunakan untuk mengambil data. Modul ini belum membahas POST/PUT/DELETE. 
JSON Format pertukaran data berbasis pasangan key-value dan array. 
Retrofit Type-safe HTTP client yang mengubah interface Kotlin menjadi request HTTP. 
Converter Gson Mengonversi JSON response menjadi object DTO Kotlin. 
DTO Data Transfer Object; bentuk data yang mengikuti struktur response API. 
Repository Mengabstraksi asal data agar ViewModel tidak bergantung langsung pada Retrofit. 
Catatan pedagogis 
Modul ini sengaja menggunakan Retrofit callback (Call.enqueue) agar fokus pada REST, JSON, dan arsitektur data. 
Pada modul berikutnya implementasi network akan direfactor menggunakan Kotlin Coroutines dan Flow.

Langkah 7 — Definisikan Endpoint Retrofit 
data/remote/StudentApiService.kt 
package com.example.navigationlab.data.remote 
 
import com.example.navigationlab.data.remote.dto.UserDto 
import com.example.navigationlab.data.remote.dto.UserResponse 
import retrofit2.Call 
import retrofit2.http.GET 
import retrofit2.http.Path 
import retrofit2.http.Query 
 
interface StudentApiService { 
 
    @GET("users") 
    fun getUsers( 
        @Query("limit") limit: Int = 10 
    ): Call<UserResponse> 
 
    @GET("users/{id}") 
    fun getUser( 
        @Path("id") id: Int 
    ): Call<UserDto> 
} 
Anotasi @GET menentukan HTTP method dan path endpoint. @Query menambahkan query parameter, 
sedangkan @Path mengganti bagian dinamis pada URL.

Langkah 8 — Buat Retrofit Client 
data/remote/RetrofitClient.kt 
package com.example.navigationlab.data.remote 
 
import retrofit2.Retrofit 
import retrofit2.converter.gson.GsonConverterFactory 
 
object RetrofitClient { 
    private const val BASE_URL = "https://dummyjson.com/" 
 
    val apiService: StudentApiService by lazy { 
        Retrofit.Builder() 
            .baseUrl(BASE_URL) 
            .addConverterFactory(GsonConverterFactory.create()) 
            .build() 
            .create(StudentApiService::class.java) 
    } 
} 
Perhatikan BASE_URL 
Retrofit mengharuskan base URL diakhiri dengan karakter /. Path seperti users akan digabungkan dengan base URL 
saat request dibuat.

data/remote/StudentRemoteDataSource.kt 
package com.example.navigationlab.data.remote 
 
import com.example.navigationlab.data.remote.dto.UserDto 
import com.example.navigationlab.data.remote.dto.UserResponse 
import retrofit2.Call 
import retrofit2.Callback 
import retrofit2.Response 
 
class StudentRemoteDataSource( 
    private val api: StudentApiService 
) { 
    fun getStudents(callback: (Result<List<UserDto>>) -> Unit) { 
        api.getUsers().enqueue(object : Callback<UserResponse> { 
            override fun onResponse( 
                call: Call<UserResponse>, 
                response: Response<UserResponse> 
            ) { 
                val body = response.body() 
                if (response.isSuccessful && body != null) { 
                    callback(Result.success(body.users)) 
                } else { 
                    callback(Result.failure(Exception("HTTP ${response.code()}"))) 
                } 
            } 
 
            override fun onFailure( 
                call: Call<UserResponse>, 
                t: Throwable 
            ) { 
                callback(Result.failure(t)) 
            } 
        }) 
    } 
 
    fun getStudent(id: Int, callback: (Result<UserDto>) -> Unit) { 
        api.getUser(id).enqueue(object : Callback<UserDto> { 
            override fun onResponse(call: Call<UserDto>, response: Response<UserDto>) { 
                val body = response.body() 
                if (response.isSuccessful && body != null) { 
                    callback(Result.success(body)) 
                } else { 
                    callback(Result.failure(Exception("HTTP ${response.code()}"))) 
                } 
            } 
 
            override fun onFailure(call: Call<UserDto>, t: Throwable) { 
                callback(Result.failure(t)) 
            } 
        }) 
    } 
}

interface StudentRepository { 
    fun getStudents(callback: (Result<List<Student>>) -> Unit) 
    fun getStudent(id: Int, callback: (Result<Student>) -> Unit) 
} 
data/repository/DefaultStudentRepository.kt 
package com.example.navigationlab.data.repository 
 
import com.example.navigationlab.data.model.Student 
import com.example.navigationlab.data.remote.StudentRemoteDataSource 
import com.example.navigationlab.data.remote.dto.toStudent 
 
class DefaultStudentRepository( 
    private val remoteDataSource: StudentRemoteDataSource 
) : StudentRepository { 
 
    override fun getStudents( 
        callback: (Result<List<Student>>) -> Unit 
    ) { 
        remoteDataSource.getStudents { result -> 
            callback(result.map { users -> users.map { it.toStudent() } }) 
        } 
    } 
 
    override fun getStudent( 
        id: Int, 
        callback: (Result<Student>) -> Unit 
    ) { 
        remoteDataSource.getStudent(id) { result -> 
            callback(result.map { it.toStudent() }) 
        } 
    } 
}

Langkah 12 — Refactor HomeViewModel 
ui/home/HomeViewModel.kt 
class HomeViewModel( 
    private val repository: StudentRepository 
) : ViewModel() { 
 
    var uiState by mutableStateOf(HomeUiState()) 
        private set 
 
    init { loadStudents() } 
 
    fun loadStudents() { 
        uiState = uiState.copy(isLoading = true, errorMessage = null) 
 
        repository.getStudents { result -> 
            result 
                .onSuccess { data -> 
                    uiState = HomeUiState(students = data) 
                } 
                .onFailure { error -> 
                    uiState = HomeUiState( 
                        errorMessage = error.message ?: "Gagal mengambil data" 
                    ) 
                } 
        } 
    } 
}

Langkah 14 — Tampilkan Loading, Error, dan Data pada HomeScreen 
UI perlu membedakan tiga kondisi utama. Jangan hanya menampilkan list karena request network dapat 
membutuhkan waktu atau gagal. 
Potongan HomeScreen.kt 
@Composable 
fun HomeScreen( 
    uiState: HomeUiState, 
    onStudentClick: (Int) -> Unit, 
    onRetry: () -> Unit 
) { 
    when { 
        uiState.isLoading -> { 
            Box(Modifier.fillMaxSize(), contentAlignment = Alignment.Center) { 
                CircularProgressIndicator() 
            } 
        } 
 
        uiState.errorMessage != null -> { 
            Column( 
                modifier = Modifier.fillMaxSize().padding(24.dp), 
                verticalArrangement = Arrangement.Center 
            ) { 
                Text(uiState.errorMessage) 
                Button(onClick = onRetry) { Text("Coba Lagi") } 
            } 
        } 
 
        else -> { 
            LazyColumn { 
                items(uiState.students) { student -> 
                    TextButton(onClick = { onStudentClick(student.id) }) { 
                        Text("${student.id} - ${student.name}") 
                    } 
                } 
            } 
        } 
    } 
}

9. Troubleshooting Singkat 
Gejala Pemeriksaan 
UnknownHostException Periksa koneksi internet emulator/perangkat dan permission INTERNET. 
HTTP 404 Periksa base URL, path @GET, @Path, dan ID yang diminta. 
Expected BEGIN_OBJECT / parsing error Periksa apakah DTO sesuai struktur JSON yang diterima. 
Data kosong Periksa response body dan parameter limit/query. 
Cleartext HTTP traffic not permitted Gunakan endpoint HTTPS. DummyJSON pada modul ini menggunakan HTTPS. 
UI tidak berubah Pastikan ViewModel benar-benar mengubah Compose state setelah callback selesai. 
Crash setelah model berubah Perbarui semua pemakaian field Student dari program/year menjadi email/university. 
Detail membuka ID salah Periksa route detail/{studentId}, @Path id, dan nilai argument dari backStackEntry. 
10. Ringkasan 
Pada praktikum ini NavigationLab beralih dari sumber data in-memory ke REST API. Retrofit mendefinisikan 
request HTTP melalui interface Kotlin, Gson mengubah JSON menjadi DTO, remote data source menangani 
komunikasi API, repository memetakan DTO ke model aplikasi, ViewModel mengelola loading/success/error 
state, dan Compose UI hanya merender state. Arsitektur yang sudah dibangun pada Modul 06 tetap 
dipertahankan sehingga perubahan sumber data tidak menyebar ke seluruh aplikasi. 
Jembatan ke Modul Berikutnya 
Callback pada modul ini bersifat sementara untuk memisahkan fokus konsep network. Pada materi berikutnya, 
proses asinkron akan disederhanakan menggunakan Kotlin Coroutines dan Flow.
